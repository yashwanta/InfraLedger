# User guide — Domains

Never lose a domain to an expired registration.

## Add a domain

1. Select **Add record** and choose the organization.
2. Enter the domain name, registrar, DNS provider, expiration date and auto-renew setting (Enabled, Disabled, Unknown).
3. Select **Create record**.

## Tips

- Domains with expiration dates appear on the Expirations page within 90 days of expiry.
- Link the registrar login from the Password vault under **Related records**.
