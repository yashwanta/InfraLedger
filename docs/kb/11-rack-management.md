# User guide — Rack management

See server and network racks unit by unit.

## Add a rack

1. Select **Add rack** and choose the organization.
2. Enter the capacity in rack units (default 42U), and optionally the location, room or row, power and cooling.
3. Select **Create record**.

## Place devices

- Select **+ Place a device** under a rack to add a new asset already assigned to it, or edit an existing asset and set its rack, starting unit and height.
- Each rack card shows a front elevation, units occupied and utilization percentage. Click a device to open it.

## Validation

- Devices cannot overlap or extend past the top or bottom of the rack.
- A rack's capacity cannot be reduced below the devices already installed.
- A rack with devices still placed in it cannot be moved to the recycle bin.
