# User guide — Asset templates

Templates add your own custom fields to assets.

## Create a template

1. Select **Add record**.
2. Enter a name, for example **Managed workstation**.
3. Enter the custom field names, **one per line**, such as **Operating system**, **CPU**, **Disk encryption**.
4. Select **Create record**.

## Use a template

Edit an asset and choose the template under **Custom asset template**. Its fields appear in the form; fill them in and save. The values are shown on the asset's detail view.
