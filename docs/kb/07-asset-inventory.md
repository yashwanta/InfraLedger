# User guide — Asset inventory

Track every device from purchase to retirement: servers, switches, firewalls, laptops, printers and more.

## Add a device

1. Select **Add record** and choose the organization.
2. Fill in what you know: device type, manufacturer, model, serial, management IP, MAC address, lifecycle status and who it is assigned to.
3. Optionally set location, rack position, purchase date, cost and warranty expiration.
4. Select **Create record**.

## Rack placement

Set **Rack**, **Starting rack unit** and **Rack height (U)** to place the device in a rack. InfraLedger rejects positions that overlap another device or fall outside the rack.

## Custom fields

Choose a **Custom asset template** to add extra fields defined on the Asset templates page, such as operating system or disk encryption.

## Tips

- Warranty expirations appear on the Expirations page.
- Devices received from a purchase order are created here automatically with status **In stock**.
- Use **Import CSV** to add many devices at once, and **Export** to download the current list.
