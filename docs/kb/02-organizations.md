# User guide — Organizations

Organizations are the clients, companies or business units you support. Almost every other record belongs to one organization.

## Add an organization

1. Select **Add organization**.
2. Enter the name, and optionally the primary domain, industry, contact email, phone and status (Active, Onboarding, Needs review, Inactive).
3. Select **Create record**.

## Working with organizations

- The table shows each organization's asset count, documentation coverage and status.
- Open an organization to see **Linked documentation**: every record that belongs to it.
- Use the **organization selector** in the top bar to limit the whole app to one organization.

## Rules

- An organization cannot be moved to the recycle bin while records still belong to it. Move or delete those records first.
- Editors limited to specific organizations cannot create new organizations; ask an admin.
- Organizations are created with the form; CSV import is not available for them.
