# User guide — Processes & runbooks

Runbooks are repeatable checklists, such as onboarding, patching or backup verification.

## Create a runbook

1. Select **Add record** and choose the organization.
2. Enter a name, process owner and optional review date.
3. Enter the checklist with **one step per line**.
4. Select **Create record**.

## Work through a checklist

- Open the runbook and tick each step as you complete it. Progress is saved immediately.
- The status updates automatically: **In progress** while steps remain, **Completed** when every step is ticked.
- The list shows completion as **steps done / total steps**.

## Tips

- Editing the checklist keeps the ticked state of steps whose text did not change.
- When importing runbooks from CSV, separate steps in the `steps` column with a vertical bar (`|`).
