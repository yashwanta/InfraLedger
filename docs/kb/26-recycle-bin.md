# User guide — Recycle bin

Deleted records go here first, so mistakes can be undone.

## Delete a record

Open the record and select **Move to recycle bin**, then confirm. Records that other records still link to (for example a rack with devices in it) must be unlinked first.

## Restore a record

Select **Restore** next to the record. InfraLedger checks that linked records still exist before restoring it.

## Notes

The recycle bin is available to admins and editors.
