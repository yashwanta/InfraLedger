# User guide — Certificates

Track TLS/SSL certificates and their expiry dates.

## Add a certificate

1. Select **Add record** and choose the organization.
2. Enter the common name or hostname, issuer, SHA-256 fingerprint, expiration date and status (Active, Expiring, Expired, Revoked).
3. Select **Create record**.

## Notes

- Expiry warnings come from the dates you record. InfraLedger does not check live certificates automatically.
- Certificates appear on the Expirations page within 90 days of expiry.
