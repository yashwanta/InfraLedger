# User guide — Diagrams

Draw network topologies, traffic flows and service dependencies, linked to your inventory.

## Create a diagram

1. Select **New diagram**, choose the organization and diagram type, and create it. The editor opens.
2. In **Diagram tools**, enter a component label, choose a type (device, cloud, firewall, switch, server, workstation, service) and optionally link an inventory asset. Select **Add component**.
3. Under **Add a connection**, choose the two components and a protocol or flow label, such as `HTTPS · TCP 443`.

## Edit

- Drag components to arrange them.
- Click a component to change its label, type or linked asset, or to remove it.
- Remove a connection with the **×** next to it in the Connections list.

## Save and export

- Changes are not stored until you select **Save diagram**. The toolbar shows **Unsaved changes** until you do, and InfraLedger warns you before you leave with unsaved changes.
- Select **Export SVG** to download the diagram as an image.
