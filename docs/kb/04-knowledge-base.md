# User guide — Knowledge base

The knowledge base holds articles: how-to guides, troubleshooting notes, policies and anything your team needs to know.

## Write an article

1. Select **New article**.
2. Enter a title and choose the organization.
3. Optionally set a category, publication status (Draft, Published, Needs review), owner and next review date.
4. Write the content in Markdown and select **Create record**.

## Supported formatting

- A line starting with one, two or three hash signs is a heading.
- A line starting with a dash or a number and full stop is a list item.
- Wrap text in double asterisks for **bold**, and in backticks for `inline code`.
- Three backticks on their own line start and end a code block.

## Versions and review

- Every save creates a new version. Open the article and select **Version history** to see earlier versions or **Restore this version**. Restoring creates a new version, so nothing is lost.
- Articles with a **Next review** date appear on the Expirations page as they come due.

## Sharing with clients

Set **Visibility** to **Client visible** to let client users of that organization read the article. Team comments are never shown to clients.
