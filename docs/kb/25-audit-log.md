# User guide — Audit log

A server-recorded history of sign-ins, changes and secret access. Admins only.

## What is recorded

- Sign-ins and workspace setup
- Records created, updated, deleted and restored
- Vault secret reveals
- Exports, user changes, API token changes and MFA changes

The page shows the most recent 1,000 events with time, actor, action, record and details.

## Export

Select **Export audit** to download the events as JSON for long-term retention.
