# User guide — Favorites

Favorites keep the records you use most one click away.

## Add or remove a favorite

1. Open any record.
2. Select **Favorite** at the top of the record. It changes to **Favorited**.
3. Select it again to remove the favorite.

## Using the Favorites page

- Favorites appear as cards showing the record type and organization. Click a card to open it.
- Favorites are personal: each user has their own list.
- The organization selector also filters this page.
