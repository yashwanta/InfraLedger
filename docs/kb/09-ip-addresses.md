# User guide — IP addresses

Allocate individual IPv4 addresses without duplicates.

## Add an address

1. Select **Add record**, or open a network and select **Allocate IP address**.
2. Choose the network and enter the IPv4 address.
3. Optionally link the assigned asset, hostname and MAC address, and set the allocation status: Assigned, Reserved, DHCP or Available.
4. Select **Create record**.

## Validation

- The address must be a valid IPv4 address inside the selected network.
- The same address cannot be allocated twice in a network.

## Tips

Filter by allocation status to find reserved or available addresses quickly.
