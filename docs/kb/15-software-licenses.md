# User guide — Software licenses

Track subscriptions and seats so you never overbuy or lapse.

## Add a license

1. Select **Add record** and choose the organization.
2. Enter the product or edition, purchased seats, assigned seats, annual cost, renewal date and status (Active, Trial, Expired, Cancelled).
3. Select **Create record**.

## Tips

- The Reports page totals **License seats available** (purchased minus assigned).
- Renewal dates appear on the Expirations page as they approach.
