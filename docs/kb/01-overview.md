# User guide — Overview

The Overview is your home page: a summary of the workspace for the organization selected in the top bar.

## What you see

- **Stat cards:** number of organizations, documented assets, knowledge articles and upcoming expirations (due or overdue within 90 days).
- **Your organizations:** the first five organizations with asset count, documentation coverage and status. Select **View all** to open Organizations.
- **Quick actions:** shortcuts to add a device, write an article, document a network or create a purchase order.
- **Recently updated documentation:** the latest knowledge base articles.
- **Documentation coverage:** the average coverage across organizations.
- **Expirations & reviews:** the next items that are due.
- **Connected infrastructure:** a preview of the first diagram.

## Documentation coverage

Coverage measures how many of five core record types an organization has: assets, articles, passwords, networks and contacts. Each type is worth 20%. **80% or more** shows as **Well documented**.

## Tips

- Use the organization selector to see the overview for a single client.
- **Create new** in the heading starts a new knowledge base article.
